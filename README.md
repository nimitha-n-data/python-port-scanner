# 🔎 Port Scanner GUI using Python

## 📌 About the Project

This project is a graphical Port Scanner developed using Python and Tkinter.

The application allows a user to enter a target hostname or IP address and scan ports from 1 to 1000. It identifies open ports and displays the results through a simple graphical interface.

## 🛠️ Technologies Used

- Python
- Tkinter
- Socket Programming
- Multithreading

## ⚙️ Features

- Simple graphical user interface
- Target hostname/IP input
- Port scanning from 1 to 1000
- Open port detection
- Multithreaded scanning
- Scan completion status
- Displays total scanning time
- Error handling for invalid hosts

## 🔄 How It Works

1. The user enters a target hostname or IP address.
2. The application resolves the hostname to an IP address.
3. Multiple threads are created to scan ports concurrently.
4. Open ports are identified using socket connections.
5. The results are displayed in the GUI.
6. The application displays the total time taken for the scan.

## 🎯 Objective

The objective of this project was to apply Python programming and basic networking concepts to develop a practical GUI-based application.
